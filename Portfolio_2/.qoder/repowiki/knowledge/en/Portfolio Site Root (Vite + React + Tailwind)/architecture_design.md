The root is a thin Vite entry point: `index.html` declares the `<div id="root">` mount target and loads `/src/main.jsx`, which the child `app_shell` module bootstraps into React. Build tooling is centralized here — `vite.config.js` enables the React plugin, sets output to `dist/` with ES2019 target and CSS code splitting; `tailwind.config.js` extends Tailwind with the site's brand palette (`ink`, `paper`, `haze`, `mist`, `brand.*`, `accent.*`), fonts (`Sora`, `Inter`, `JetBrains Mono`), animations (`fade-up`, `caret`, `drift`), and a full 0–100 opacity scale consumed by every component; `postcss.config.js` chains Tailwind and Autoprefixer. Shared assets (favicon, Google Fonts preconnect) live in `index.html` so all children reference them uniformly.
