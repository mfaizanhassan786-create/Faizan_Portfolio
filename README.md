# Faizan Hassan Portfolio

Personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

The site is configured for deployment to GitHub Pages at `/faizan-portfolio/`.
Portfolio content and assets live in `src/` and `public/`.
